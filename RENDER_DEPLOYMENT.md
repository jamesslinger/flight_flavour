# Flight Flavour - Render.com Deployment Guide

## 🚀 Deploying to Render.com

### Step 1: Deploy the Backend API Proxy

1. **Create a new Web Service on Render.com**
   - Go to [Render.com](https://render.com) and sign in
   - Click "New +" → "Web Service"
   - Connect your GitHub repository

2. **Configure the Backend Service**
   - **Name**: `flight-flavour-api` (or your preferred name)
   - **Environment**: `Node`
   - **Build Command**: `npm install` (using server-package.json)
   - **Start Command**: `npm start`
   - **Root Directory**: `/` (leave empty)

3. **Set Environment Variables**
   ```
   KIWI_API_KEY=your_actual_kiwi_api_key
   FRONTEND_URL=https://your-frontend-app-name.onrender.com
   NODE_ENV=production
   ```

4. **Deploy the Backend**
   - Click "Create Web Service"
   - Wait for deployment to complete
   - Note the backend URL (e.g., `https://flight-flavour-api.onrender.com`)

### Step 2: Deploy the Frontend

1. **Create a Static Site on Render.com**
   - Click "New +" → "Static Site"
   - Connect your GitHub repository

2. **Configure the Frontend Service**
   - **Name**: `flight-flavour` (or your preferred name)
   - **Branch**: `main` or your deployment branch
   - **Build Command**: `cd client && npm install && npm run build:prod`
   - **Publish Directory**: `client/build`

3. **Set Environment Variables for Frontend**
   ```
   REACT_APP_PROXY_URL=https://your-backend-service-name.onrender.com
   ```

4. **Update Frontend Configuration**
   - In `client/.env.production`, replace `your-render-app-name.onrender.com` with your actual backend URL
   - Commit and push the changes

5. **Deploy the Frontend**
   - Click "Create Static Site"
   - Wait for deployment to complete

### Step 3: Update CORS Settings

In your backend service environment variables, make sure `FRONTEND_URL` is set to your frontend's Render.com URL:

```
FRONTEND_URL=https://flight-flavour.onrender.com
```

### Step 4: Test the Deployment

1. Visit your frontend URL
2. Try making a flight search
3. Check the Network tab in browser dev tools to ensure requests go to `/api/v2/search`

## 🔧 Troubleshooting

### CORS Issues Persist
- Verify `FRONTEND_URL` in backend environment variables matches your frontend URL exactly
- Check backend logs for proxy errors
- Ensure the API key is set correctly in backend environment variables

### API Calls Fail
- Check that `REACT_APP_PROXY_URL` in frontend environment variables points to your backend
- Verify the backend service is running and accessible
- Check browser Network tab for the actual request URLs

### Build Fails
- Ensure all environment variables are set in Render.com dashboard
- Check build logs for specific errors
- Verify `server-package.json` and `client/package.json` are correct

## 🔒 Security Notes

- API keys are stored as environment variables, not in code
- Backend handles API key securely
- Frontend only communicates with your backend proxy
- No sensitive data is exposed to the client

3. No CORS issues since everything goes through your backend
4. API responses are returned to your frontend
